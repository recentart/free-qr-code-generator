Tips for codes that scan every time

      
    
        
  • Use a dark colour on a light background. Some scanners can’t read light-on-dark codes.
    • 
        
  • Keep the quiet zone (the empty border). Codes that touch text or pictures often fail to scan.
    • 
        
  • Print it at least 2 cm (about 0.8 in) wide, and bigger if people will scan it from further away.
    • 
        
  • Shorter content makes a simpler code. Use a short web address where you can.
    • 
        
  • Test the code with a phone before you print lots of copies.

Questions and answers

      

        

          Is this QR code generator really free?
          
Yes. There’s no sign-up and no watermark, and you can create and download as many codes as you like.

        

        

          Do the QR codes expire?
          
No. These are static QR codes: the information is stored in the code itself, not on a server, so a code keeps working for as long as whatever it points to exists. A static code can’t be edited after you print it. If the details change, make a new code.

        

        

          Is my information private?
          
Yes. The code is made by JavaScript running in your browser, and nothing you type is sent to our server or stored. That includes Wi-Fi passwords.

        

        

          How do I make a Wi-Fi QR code?
          
Choose Wi-Fi, then enter the network name exactly as it appears (capital letters matter), the password and the security type. Guests point their phone camera at the code and tap to join. Most home routers use WPA/WPA2 (WPA3 networks usually work with this setting too).

        

        

          Should I download a PNG or an SVG?
          
PNG works everywhere, including documents, websites, slides and messages. SVG is a vector file that stays sharp at any size, so it’s the better choice for printing and for design tools.

        

        

          What does error correction do?
          
It adds backup data so a code can still be read if part of it is dirty or damaged. Medium suits most uses. Choose Quartile or High for printed codes that may get scuffed. Higher levels make the code denser.
